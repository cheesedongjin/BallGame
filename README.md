# 🔴 공게임

숫자가 적힌 공들을 **조건에 맞는 순서대로** 클릭하는 게임입니다.

🔗 **[바로 플레이하기](https://cheesedongjin.github.io/BallGame/)**

---

## 🎮 How to Play

1. 화면에 숫자 공들이 등장합니다
2. 문제에서 요구하는 **조건**을 읽으세요
3. 타이머가 끝나기 전에 공을 순서대로 클릭!
4. 총 **10문제**, 최고 점수를 노려보세요

---

## ⚡ 점수 규칙

| 상황 | 점수 |
|------|------|
| 정답 클릭 | `+10 + 남은 시간(초)` |
| 오답 / 순서 틀림 | `−5` |

빠를수록 높은 점수! ⏱️
